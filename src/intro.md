# SolidCraft Design

This is where I share design docs and RFC drafts for [SolidCraft](https://github.com/tangency-labs/solidcraft) in public, so contributors can read and comment on them early, before any code lands.

## Statuses

| Status | Meaning |
|---|---|
| Draft | Written down, still changing. Nothing is decided. |
| Under review | Open for comment, with named reviewers. |
| Accepted | Agreed. The design moves to `docs/rfcs/` in the SolidCraft repository and work starts. |
| Rejected | Decided against. The page stays, with the reason. |

## Feedback

Open an issue or a pull request on [tangency-labs/design](https://github.com/tangency-labs/design). Issues are good for questions and objections; a PR is best for a concrete wording or diagram fix. Every page has an edit link at the top right.

Accepted designs move to [`docs/rfcs/`](https://github.com/tangency-labs/solidcraft/tree/main/docs/rfcs) in tangency-labs/solidcraft, where they are kept next to the code.
